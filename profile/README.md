## Everything you need, nothing you don't

|  |  |
| :-- | :-- |
| **Custom Sky** | Six skies built in, and any FabricSkyboxes pack you already have works without that mod installed. |
| **Look inside a shulker** | Point at a shulker box and its contents come up, in the world or in your inventory. Lock one open to keep reading it. |
| **Zoom** | Hold a key and pull the horizon in. Adjustable, smooth, and nothing else has to be installed for it. |
| **Your music, on the HUD** | What you are playing, with the album art. No account to connect. Windows only for now. |
| **Recolour the glint** | The enchantment shimmer in any colour you like, or gone entirely if you would rather see the item. |
| **Boss Bar** | Move it, resize it, recolour it, and say how many bars you want on screen at once. |
| **Armor Status** | Up the side or along the bottom, only the pieces you care about, in colours that follow the wear. |
| **A HUD you arrange** | Drag any readout where you want it and pull its corner to resize. Your layout, not a fixed one. |

Enable and disable them without restarting, tune each one on its own, and save a setup as a preset for building, PvP, or anything else. Every mod page has a Reset button when you want its defaults back.

The full client runs on **1.21.4, 1.21.11, 26.2 and 26.3**. Every other version still launches from the launcher — back to 1.0, each with the Java it needs — you just get Minecraft without the rest of what we add.
