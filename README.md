# MekiksClient

A free Minecraft: Java Edition client for Windows — built for performance, customisation, and a cleaner way to play.

**[Download at mekiks.com](https://mekiks.com)**

---

## What it does

**Launcher**
- Manages Minecraft versions and profiles
- Installs Fabric for you — no manual setup
- Installs and updates Sodium automatically, matched to your game version
- Picks a compatible Java runtime instead of whatever happens to be on your PATH
- Updates itself; you install once

**In-game (Right Shift)**
- Mods menu with per-mod settings
- HUD modules — FPS, ping, coordinates, CPS, keystrokes, armour status
- Zoom, custom crosshair, fullbright, colour grading, 2D items, hit colour
- Drag-and-drop HUD editor with snapping
- Client badge beside other MekiksClient players

Currently targets **Minecraft 1.21.11** on Fabric. More versions are planned.

## Source code

The client source is not public. This repository exists for releases, issues and documentation.

## Bugs and requests

Open an [issue](../../issues). Helpful things to include:

- What you were doing when it happened
- Your Minecraft version and profile loader
- The launcher log — `%APPDATA%\MekiksClient\logs\launcher.log`
