## Everything you need, nothing you don't

|  |  |
| :-- | :-- |
| **Custom Sky** | Six skies built in, and any FabricSkyboxes pack you already have works without that mod installed. |
| **Look inside a shulker** | Hover a shulker box in your inventory or a chest and its contents come up beside it. Lock one open to keep reading it. |
| **Zoom** | Hold a key and pull the horizon in. Adjustable, smooth, and nothing else has to be installed for it. |
| **Your music, on the HUD** | What's playing, with the album art. No account to connect. Windows only for now. |
| **Recolour the glint** | The enchantment shimmer in any colour you like, or gone entirely if you would rather see the item. |
| **Boss Bar** | Move it, resize it, recolour it, and say how many bars you want on screen at once. |
| **Armor Status** | Up the side or along the bottom, only the pieces you care about, in colours that follow the wear. |
| **A HUD you arrange** | Drag any readout where you want it and pull its corner to resize. Your layout, not a fixed one. |

Enable and disable them without restarting, tune each one on its own, and save a setup as a config — one for PvP, one for building. Every mod page has a Reset button when you want its defaults back.

The full client runs on **1.21.4, 1.21.11, 26.2 and 26.3**. Every other version still launches from the launcher — back to 1.0, each with the Java it needs — you just get Minecraft without the rest of what we add.

## Questions

<details>
<summary><b>Does it work with other mods?</b></summary>

Yes, if they are Fabric mods. The launcher installs Fabric, and our own mods sit alongside anything else you add for it, including Iris shaders and Sodium.

</details>

<details>
<summary><b>Windows says it protected my PC. Is that normal?</b></summary>

Windows shows that warning for any app it has not seen many times, ours included. If you got the file from mekiks.com, click "More info", then "Run anyway". If it came from anywhere else, do not run it.

</details>
